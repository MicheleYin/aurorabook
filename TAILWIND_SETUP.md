# Tailwind CSS Setup for Leptos Frontend

## Overview

Tailwind CSS is now configured for the Leptos frontend. Since Trunk uses Lightning CSS (which doesn't directly support Tailwind), we process Tailwind CSS separately and integrate it with Trunk.

## How It Works

1. **Source CSS**: `src/index.css` - Contains Tailwind directives and custom CSS
2. **Processed CSS**: `src/index.processed.css` - Generated by Tailwind CLI
3. **Build Process**: Tailwind processes the CSS before Trunk builds

## Development

### Automatic CSS Processing

When running `bun tauri dev`:
- Tailwind CSS watcher runs in the background (`bun run dev:css`)
- Trunk dev server runs (`trunk serve`)
- CSS is automatically rebuilt when `src/index.css` changes

### Manual CSS Build

To build CSS manually:

```bash
cd src-frontend
bun run build:css
```

To watch CSS changes:

```bash
cd src-frontend
bun run watch:css
```

## Configuration Files

- **`tailwind.config.js`** - Tailwind configuration
  - Scans `src/**/*.rs` files for Tailwind classes
  - Includes all your custom theme colors and settings
  - Uses `@tailwindcss/typography` and `tailwindcss-animate` plugins

- **`postcss.config.js`** - PostCSS configuration
  - Processes Tailwind and Autoprefixer

- **`src/index.css`** - Source CSS file
  - Contains `@tailwind` directives
  - Includes all CSS custom properties (CSS variables)
  - Custom animations and styles

## Using Tailwind in Leptos

Tailwind classes work exactly the same in Leptos as in React:

```rust
use leptos::*;

#[component]
fn Button() -> impl IntoView {
    view! {
        <button class="px-4 py-2 bg-primary text-primary-foreground rounded-lg hover:bg-primary/90">
            "Click me"
        </button>
    }
}
```

## Build Process

### Development
1. `bun run dev:css` - Watches and rebuilds CSS
2. `trunk serve` - Serves the app

### Production
1. `bun run build:css` - Builds minified CSS
2. `trunk build --release` - Builds the app

## Notes

- The processed CSS file (`index.processed.css`) is gitignored
- Tailwind scans Rust files (`.rs`) for class names
- All Tailwind utilities, components, and custom theme work as expected
- Dark mode support via `class` strategy (add `dark` class to HTML element)

## Troubleshooting

### CSS not updating
- Make sure `bun run dev:css` is running
- Check that `src/index.processed.css` exists
- Verify Tailwind is scanning your Rust files

### Classes not working
- Check `tailwind.config.js` content paths include your Rust files
- Verify the class name is correct
- Check browser console for CSS loading errors

### Build fails
- Ensure `bun install` has been run in `src-frontend/`
- Check that `src/index.css` exists
- Verify Tailwind CLI is installed: `bunx tailwindcss --version`
