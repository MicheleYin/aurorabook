# AuroraBook Frontend (Leptos)

This is the Leptos-based frontend for AuroraBook, replacing the React/TypeScript frontend.

## Development

### Prerequisites

- Rust toolchain (latest stable)
- Trunk: `cargo install trunk` (already installed ✓)
- Bun: For running Tailwind CSS build scripts

### Running Development Server

**Option 1: Using Tauri (Recommended)**
```bash
# From project root
bun tauri dev
```

This will:
1. Start Tailwind CSS watcher (rebuilds CSS on changes)
2. Start Trunk dev server on `http://localhost:1420`
3. Build and run the Tauri app

**Option 2: Standalone**
```bash
cd src-frontend
./dev.sh
```

Or manually:
```bash
cd src-frontend
# Terminal 1: Watch CSS
bun run dev:css

# Terminal 2: Run Trunk
trunk serve
```

### Building for Production

```bash
cd src-frontend
bun run build:css  # Build Tailwind CSS
trunk build --release  # Build Leptos app
```

The output will be in `../dist/`.

## Tailwind CSS

Tailwind CSS is fully configured and working. See `TAILWIND_SETUP.md` for details.

- **Source**: `src/index.css` - Contains Tailwind directives
- **Processed**: `src/index.processed.css` - Generated by Tailwind CLI
- **Config**: `tailwind.config.js` - Tailwind configuration

### Using Tailwind in Leptos

Tailwind classes work exactly the same as in React:

```rust
view! {
    <button class="px-4 py-2 bg-primary text-primary-foreground rounded-lg">
        "Click me"
    </button>
}
```

## Notes

- This frontend uses Leptos 0.6 with CSR (Client-Side Rendering)
- Tauri commands are called via `__TAURI__` global object
- Types are converted from TypeScript to Rust with serde for serialization
- Tailwind CSS is processed separately and integrated with Trunk
